Documentation Guide & Format Analysis Conventions

Project: LEGO Star Wars Reversing & Format Documentation

1. Game-Scoped Documentation Rule

This documentation suite covers formats, archives, and assets specific to LEGO Star Wars (The Video Game, The Original Trilogy, and The Complete Saga using Classic Nu2 / NU20 containers). It follows the two-tier LEGO reversing documentation hierarchy:

  • Scope of This Game Documentation: Pages under Formats/ document only the format versions present in the Classic LEGO Star Wars releases. Later NXG HSEM, DX11, or NTT variants used by subsequent titles are kept to minimal notes so an implementer can build a complete LEGO Star Wars parser without cross-era branches.
  • Parent Shared LEGO Documentation (../../reversing/docs/Travellers_Tales/): Combines format variants across all Traveller's Tales titles and engine generations. Consult the parent docs for cross-game format evolution.

2. Two Complementary Documentation Trees

  1. Format Analysis (Formats/): Follows binary format origins from executable and archive containers (.xbe/.xex, .bin/ELF, .exe, .dat) to extracted formats (datFormats/).
  2. Game Files & Asset Use (Files/): Documents directory hierarchies, disc inventories, sound banks, character definitions, and level scripts through a combined virtual filesystem.

3. Expected Level of Detail (Standalone Clean-Room Standard)

Every understood format page in this module must be a complete, standalone specification capable of guiding a clean-room parser or converter implementation for LEGO Star Wars without inspecting RemakeEngine source code. Format pages must include:

  • Exact signatures, version constants, and little/big-endian rules.
  • Full byte-offset structure tables, self-relative pointer resolution, and mathematical inverse-bind bone matrix transforms.
  • Layer/LOD filtering, bounding-box deduplication, and triangle winding conventions.
  • Complete, end-to-end pseudocode covering binary parsing through final geometry reconstruction.
